# Aashi Khandelwal Portfolio Website

Welcome to the source code for my personal portfolio website! This website showcases my skills, projects, professional experience, and contact information as an AI/ML Engineer and Data Scientist.

---

## 🌟 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices.
- **Hero Section**: Introduction with profile photo, tagline, and call-to-action buttons.
- **About Me**: Highlights my background, interests, and key strengths.
- **Skills & Technologies**: Detailed overview of technical expertise across AI/ML, web frameworks, cloud, and data visualization.
- **Projects**: Featured AI/ML projects with descriptions, tech stack, and GitHub links.
- **Experience & Education**: Professional timeline and academic achievements.
- **Certifications**: Relevant AI/ML and technology certifications.
- **Contact**: Easy ways to reach out via email, phone, LinkedIn, or GitHub.
- **Footer**: Social media links and copyright.

---

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Fonts & Icons**: Google Fonts (Playfair Display, Inter), Font Awesome
- **Optional Enhancements**: Responsive navbar with hamburger menu

## 🚀 How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/Aashikhandelwal05/portfolio-website.git
```

2. Navigate to the project directory:
``` bash
cd portfolio-website
```
3. Open index.html in your browser to view the website.
